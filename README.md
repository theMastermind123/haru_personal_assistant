For the complete feature documentation, installation instructions, and project details, please visit the original repository.

## 🚀 How to Download

### Clone the Repository with Submodules

```bash
git clone --recurse-submodules https://github.com/theMasterMind123/Open-LLM-VTuber.git
cd Open-LLM-VTuber
```

If you have already cloned the repository without its submodules, initialize them with:

```bash
git submodule update --init --recursive
```
